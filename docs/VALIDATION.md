日期：2026-09-21。本机为 Windows 11 24H2，内部版本 26100，x64，主屏 2560×1600，175% 系统缩放。
SDK 10.0.401；免安装包内含 .NET 与 Windows Desktop Runtime 10.0.12。

## 已完成

- Release 编译零警告、零错误。
- 68 项核心检查通过，包括摸头识别、拖动优先、连续点击恢复、日常与二维追逐、闲置返回、抛球限速、边界碰撞、减速、暂停、设置迁移和隐藏状态组合；四档缩放坐标下还分别模拟了五分钟追球。
- 33 项桌面集成检查通过，包括宠物透明穿透、非激活窗口、三个大小、小球非激活、表情图标穿透、暂停与菜单冻结、全屏隐藏与恢复、手动隐藏优先、睡眠及安静模式收球、256 帧缓存上限。
- 真实右键菜单调用「叫出小球」能显示小球；「隐藏到托盘」同时收起宠物和小球；重复启动恢复同一实例，退出后进程正常结束。
- [自包含窗口检查原始结果](validation/v0.2.0/smoke.json) 与 [真实菜单检查](validation/v0.2.0/menu.json) 已保存。
- 全屏识别通过测试创建的覆盖主屏窗口与普通最大化窗口验证；不会将本进程窗口当成用户全屏应用。隐藏组合检查调用同一显示状态管理入口。
- 免安装 ZIP 已解压到独立目录；在 `DOTNET_ROOT` 指向不存在目录、关闭多级运行时查找时启动，33 项窗口检查通过，压缩包 SHA-256 与校验文件一致。[解压检查结果](validation/v0.2.0/portable-smoke.json)

## 30 分钟循环测试

正在进行。固定每 10 秒切换一次场景，循环覆盖二维追逐、抛球、暂停、全屏隐藏、安静、菜单、睡眠、摸头、情绪和大小变化。

检查标准在运行前确定：连续运行不少于 1800 秒；全部桌面检查通过；相对第 10 分钟预热基准，私有内存增长小于 64 MiB，句柄增长小于 50；动画缓存不超过 256 项。原始结果将完整保留。

## 验证范围与限制

- 当前实机验证是 175% 缩放。100%、125%、150%、200% 的已有移动坐标测试为模拟，不等于这些缩放档位的实机视觉与输入测试。
- 未在全新无 .NET 的虚拟机、Windows 10 实机或不同显卡上验证。自包含运行时加载路径与独立解压启动单独检查。
- 未逐一验证商业游戏、视频播放器、远程桌面和特殊覆盖层的全屏行为。检测基于主屏前台窗口边界及最大化状态，特殊窗口可使用手动隐藏。
- 未覆盖物理显示器热插拔和修改系统主屏的实机操作；模型边界变化由自动检查覆盖。
- 只在主屏工作区内活动，不会停靠其他应用窗口边缘；没有音效、养成、变身或联网。
- 分数缩放下像素宽度可能略不均匀；程序未签名。
