首个像素百变怪 Windows 试运行版本。

- 透明置顶、主屏底部闲逛，不抢键盘焦点。
- 点击回弹、拖动拉伸、落地回弹、待机眨眼与睡眠。
- 中文右键与托盘菜单，三档大小、暂停、隐藏、退出。
- 保存大小和水平位置，重复启动会显示已有桌宠。
- Windows x64 自包含免安装包，无需预装 .NET。

下载 ZIP 并完整解压后启动 `DittoDesktopPet.exe`。`SHA256SUMS.txt` 用于校验下载文件。

这是未签名的预发布版本。仅支持主屏，暂不支持全屏自动避让。实际测试范围见仓库 `docs/VALIDATION.md`，未实测环境不作兼容性保证。
