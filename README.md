# 百变怪桌宠

一小团紫色，今天更想和你玩。**v0.2.0** 带来摸头、主动撒娇、全主屏玩耍和拖动抛球。

## 开始使用

下载 `DittoDesktopPet-v0.2.0-win-x64.zip`，**完整解压**后双击 **DittoDesktopPet.exe**。无需管理员权限，也无需额外安装 .NET。

面向 Windows 10/11 x64；实际测试环境及限制见 [验证记录](docs/VALIDATION.md)。程序未签名，Windows 可能显示未知发布者提示。

| 操作 | 效果 |
| --- | --- |
| 左键点击 | 压扁回弹；连续快速戳会短暂委屈，然后恢复 |
| 不按键，在头顶轻轻来回移动 | 开心眯眼、冒出爱心；静止悬停不算抚摸 |
| 按住左键拖动 | 身体拉伸，松开后落到底部 |
| 右键 → 活泼黏人／安静陪伴 | 切换主动跟随与安静待机 |
| 右键 → 陪我玩 | 从底部陪伴切换到主屏工作区内追逐鼠标 |
| 右键 → 叫出小球 | 叫出一颗球；拖动松手可抛球，百变怪会追球、顶球 |
| 右键 → 结束玩耍 | 收起球，回到底部 |
| 右键或托盘菜单 | 大小、暂停、睡眠、隐藏、退出 |
| 双击托盘图标／再次启动 | 找回隐藏的桌宠 |

默认活泼，沿底部跟随鼠标左右移动，偶尔撒娇、小跳、伸懒腰或打哈欠。安静模式关闭主动跟随与撒娇，但仍可主动摸头或开启玩耍。身体、爱心、问号和汗滴均不抢键盘焦点；表情图标可以直接点击穿透。

玩耍时有球优先追球，没球追鼠标，并保持距离。一次只有一颗球，重复叫球会把它放回附近。连续 **60 秒没有逗宠操作**后自动结束：点击、抚摸、拖动和宠物附近的鼠标移动算互动，远处办公操作与自动顶球不延长计时。

## 安静下来与全屏避让

- 暂停或菜单打开时冻结运动、球物理和玩耍倒计时。暂停仍可拖动，松手直接安放到底部。
- 睡眠、切换安静模式和手动隐藏会结束当前玩耍。
- 主屏前台应用进入覆盖整个显示器的全屏模式时，宠物、小球和表情一起隐藏，计时暂停；退出全屏后恢复。
- 普通最大化窗口不触发自动隐藏。手动隐藏不会因退出全屏而被意外恢复。
- 部分游戏、覆盖层或特殊窗口可能无法按标准全屏窗口识别，需要时可手动隐藏。主屏之外的全屏应用不影响主屏桌宠。

三档大小为 96、128、160 逻辑像素。采用最近邻绘制，分数系统缩放可能使物理像素宽度不完全均匀。

## 设置与升级

设置保存在 `%LOCALAPPDATA%\DittoDesktopPet\settings.json`，包含大小、水平位置和活泼／安静偏好。v0.1.0 设置会自动迁移，保留大小和位置。每次启动都清醒、不处于玩耍状态；小球和短暂情绪不保存。若此时主屏正在全屏显示，自动避让会隐藏桌宠。

升级前先通过托盘退出旧版，再把新包解压到新的目录。旧版也使用同一个单实例名称，未退出旧版时再次启动只会唤回旧程序。旧版下载保留在 Releases。v0.1.0 不认识新版设置格式，回退时可能恢复默认大小和位置；如需保留回退设置，升级前备份上述设置文件。

卸载时退出并删除解压目录即可；设置目录可以另行删除。

本版不包含联网、聊天、变身、养成数值、声音、自启动、自动更新或多屏活动。

## 开发与验证

使用 `global.json` 指定的 .NET 10 SDK，在 Windows 上运行：

```powershell
dotnet run --project src/Ditto.Desktop
dotnet run --project tests/Ditto.Tests -c Release
./tools/package.ps1
```

核心模块分别管理宠物行为、短暂情绪、摸头识别、小球物理及设置。桌面模块负责窗口、托盘、鼠标位置采样和全屏检测，不安装全局按键钩子，也不读取其他应用内容。

桌面集成检查需要交互式 Windows 会话：

```powershell
./artifacts/publish/DittoDesktopPet.exe --smoke-test --output artifacts/v020-smoke
./artifacts/publish/DittoDesktopPet.exe --soak-test --output artifacts/v020-soak
```

检查模式使用独立实例和临时设置。长测持续 30 分钟，循环覆盖追逐、抛球、暂停、全屏隐藏、安静、菜单、睡眠和摸头；每 10 秒采样，资源增长以第 10 分钟的预热基准计算。长测会在桌面显示并移动测试宠物，结束后自动退出。原始判定和数据会保留，不因结果失败而改写采样。

导出真实动画帧和生成文档演示：

```powershell
./artifacts/publish/DittoDesktopPet.exe --export-demo --output artifacts/frames-v020
python tools/create_icon.py
python tools/create_demo.py
```

图片工具需要 Pillow。文档 GIF 是由应用动画帧组成的功能演示，并非桌面录屏。GitHub Actions 对推送运行核心检查、自包含打包并保留构建产物；版本标签触发预发布。
